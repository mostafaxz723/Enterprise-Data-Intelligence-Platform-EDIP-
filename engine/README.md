# engine — المعادلات الهندسية
هنا كود الحسابات الصافي (بدون قواعد بيانات ولا واجهات)، عشان يتختبر بسهولة:
- الألواح الشمسية (pvlib): إشعاع، حرارة الخلية، الفواقد.
- الرياح (windpowerlib): منحنى القدرة، كثافة الهواء، ويبل.
- الغبار وجدولة التنظيف، LCOE، ترتيب المواقع (القيود ثم الاقتصاد ثم المخاطر).
المرجع: `docs/SPEC.md` القسم 5. كل دالة لها اختبار في `tests/`.
