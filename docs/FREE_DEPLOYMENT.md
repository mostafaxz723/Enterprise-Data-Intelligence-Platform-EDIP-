# النشر بدون أي تكلفة

**كل الحدود والشروط أدناه تتغير؛ راجعي صفحة كل خدمة قبل الاعتماد عليها [تحقق].**

## المبدأ: «الساكن أولًا» (Static-first)
احسبي كل شيء على جهازك أو عبر GitHub Actions، وانشري **ملفات** (Parquet / JSON / PMTiles) على استضافة ساكنة مجانية. الموقع يقرأ الملفات مباشرة، فلا نحتاج خادم قاعدة بيانات دائمًا.

| المكوّن | خيار مجاني | ملاحظة |
|---|---|---|
| الواجهة (Next.js) | Cloudflare Pages أو Vercel (Hobby) أو GitHub Pages | Vercel Hobby للاستخدام غير التجاري |
| الخرائط والبيانات | Cloudflare R2 (طبقة مجانية) أو GitHub Releases/Pages | PMTiles ملف واحد ساكن |
| الجدولة | GitHub Actions (cron) | المستودعات العامة سخية الحدود |
| الـ API الخفيف | Hugging Face Spaces (Docker) أو Render (يغفو عند الخمول) أو Cloudflare Workers | اختاري بحسب الحمل |
| قاعدة بيانات مُدارة | Neon أو Supabase (طبقة مجانية صغيرة، مع PostGIS) | سعة صغيرة؛ نخزن فيها الجداول النهائية فقط |
| خادم كامل | Oracle Cloud «Always Free» | يطلب بطاقة للتحقق وقد يصعب التسجيل؛ لو نجح يستضيف Airflow كاملًا |
| مراقبة | UptimeRobot + Sentry (طبقات مجانية) | |
| الشات بوت | وضع «قوالب» بلا نموذج لغوي + نموذج مجاني بحدود (Ollama محليًا للتطوير) | Claude API **ليس مجانيًا** وله فاتورة منفصلة عن الاشتراك |

## كيف نتجنب الدفع كليًا
1. **لا نحتاج Airflow على الإنترنت:** نشغّله محليًا للتطوير، وننتج النتائج بـ GitHub Actions ونرفعها كملفات.
2. **الشات بوت:** نبنيه بحيث يعمل في وضعين: (أ) قوالب تفسير جاهزة من حمولة «لماذا؟» بلا نموذج لغوي، (ب) نموذج لغوي عبر `LLM_BASE_URL` (Ollama أو خدمة بطبقة مجانية) عند توفره.
3. **ضعي سقف حجم:** حافظي على الملفات المنشورة صغيرة (دقة H3 6 لمصر ≈ 28 ألف خلية فقط).
4. **حساب المبادرة السحابي (إن وُجد):** اعتبريه إضافة، لا أساسًا؛ لأن الرصيد ينتهي.
