# دليل التجهيز لأعضاء الفريق — ابدأ من هنا

الدليل ده معمول لمين **ما استخدمش Git ولا GitHub ولا conda قبل كده**. امشي على الخطوات بالترتيب ومتفوتش خطوة. كل خطوة مكتوب فيها **اكتب إيه، ومكانه فين، والمفروض يحصل إيه، وليه بنعمل كده**.

## 1) اختار الدليل المناسب لجهازك

اختار حسب **النظام اللي بتشتغل عليه فعلًا** (مش اللي مركّب جنبه):

| وضعك | اقرأ |
|---|---|
| ويندوز 10 أو 11 (الأغلبية) | [`01-windows.md`](01-windows.md) |
| ويندوز **ومعاك Virtual Machine** لينكس (Red Hat أو Ubuntu أو غيره) | [`01-windows.md`](01-windows.md). اشتغل على **ويندوز نفسه** وسيب الـ VM (التفاصيل في [`03-other-systems.md`](03-other-systems.md)) |
| Ubuntu (نظام أساسي) أو Debian أو Mint | [`02-ubuntu-linux.md`](02-ubuntu-linux.md) |
| Fedora / Red Hat / Rocky / Alma (نظام أساسي) | [`03-other-systems.md`](03-other-systems.md) |
| macOS | [`03-other-systems.md`](03-other-systems.md) |
| لينكس مركّب بس **مستخدمتوش** (مثلًا جنب ويندوز) | اشتغل على **ويندوز** → [`01-windows.md`](01-windows.md) |
| مش عارف نظامي إيه | في ويندوز: ابدأ ← اكتب `winver`. في لينكس: افتح Terminal واكتب `cat /etc/os-release` |

## 2) حدد دورك حسب رام جهازك

| رام الجهاز | الدور | بيشتغل عليه إيه | البرامج المطلوبة |
|---|---|---|---|
| **8 جيجا أو أقل** | `web` | الموقع والشاشات فقط، بدون Docker ولا Anaconda | Git + VS Code + Node.js |
| **16 جيجا** | `all` | كل حاجة: البيانات والـ API والموقع | + Anaconda + Docker Desktop |

لو مش عارف رامك: ويندوز ← `Ctrl+Shift+Esc` ← تبويب **Performance** ← **Memory**.
**جهاز 8 جيجا مش عيب.** الواجهة جزء أساسي من المنتج، وده بالظبط دور `web`.

## 3) الوقت والمساحة

| | الوقت التقريبي | المساحة على الديسك |
|---|---|---|
| دور `web` | 15 إلى 30 دقيقة | حوالي 2 جيجا |
| دور `all` | 45 دقيقة لساعتين (أغلبه تنزيل) | 25 إلى 40 جيجا |

الوقت الأكبر انتظار تنزيل. سيب الجهاز على الشاحن وخلّيه شغّال.

## 4) قبل ما تبدأ: 3 حاجات مطلوبة منك

1. **حساب GitHub** (لو معندكش: `github.com` ← Sign up بإيميل بتستخدمه فعلًا).
2. ابعت **اسم المستخدم** (username) لمصطفى (التيم ليدر) علشان يضيفك على الريبو.
3. افتح إيميلك وشوف رسالة **"Invitation to collaborate"** من GitHub وادوس **Accept invitation**. من غيرها مش هتقدر ترفع شغلك.

## 5) بعد ما تخلص التجهيز

اقرأ [`CONTRIBUTING.md`](../../CONTRIBUTING.md) من أوله. فيه مفاهيم Git بالبساطة، وشغلك اليومي، وإزاي ترجّع لو غلطت.

## لو عطلت
ابعت في جروب الفريق **3 حاجات** (من غيرها محدش يقدر يساعدك):
1. صورة الشاشة **كاملة** (مش جزء منها).
2. الأمر اللي كتبته بالظبط.
3. نظامك (ويندوز/Ubuntu...) ورامك.
